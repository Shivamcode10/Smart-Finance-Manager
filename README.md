# 💰 Smart Finance Manager

**Smart Finance Manager** is a full-stack web application designed to help users manage personal finances including tracking income, expenses, budgets, and financial insights.  

---

## 📌 Project Overview

Smart Finance Manager allows users to:

- 🧾 Add & track income and expenses
- 📊 Visualize financial data
- 🗂️ Categorize transactions
- 🧠 Get insights for better savings & budgeting
- 💼 Store finance records securely

This system includes both frontend and backend implementations to provide a seamless financial management experience. :contentReference[oaicite:2]{index=2}

## ✨ Features

### 📌 Dashboard
- Easy overview of overall finances
- Transaction summary and charts

### 💵 Transaction Management
- Add income or expense records
- Categorize each transaction
- Edit or delete entries

### 📊 Analytics & Insights
- Total income & total expense
- Category-wise spending breakdown
- Balance overview

### 🔐 User Authentication
- Register new users
- Login & role-based access
- Secure JWT auth for API calls
